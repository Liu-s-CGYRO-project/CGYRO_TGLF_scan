Transfer_tool 使用流程
---------------------

在工程总控“输入准备与转换 → Transfer_tool 运行”中，载入剖面，
选择粒子处理方案、主离子和计算半径，点击唯一的“运行 Transfer_tool”按钮。
程序依次准备粒子、运行 TGYRO、生成各半径 input.cgyro / input.tglf。

粒子方案
~~~~~~~~

* 保留所有粒子：保留各离子的密度以外属性及热 / 快类型，主离子承担准中性校正。
* 慢化快离子（热化处理）：以电荷和质量识别同种粒子。对应热杂质时将快离子密度并入该热离子；对应所选主离子时保留为独立粒子，其密度不合并，温度与流速改用主离子的值。没有同种热离子时停止；不计算真实慢化分布。
* 仅保留主离子和等效杂质：固定电子密度和初次准中性校正后的 Zeff，保留选定主离子和一种杂质。杂质质量、电荷取所选原粒子，温度及流速采用主离子值。若原剖面没有较高电荷的离子，则只保留主离子。
* 仅保留主离子：电子密度不变，主离子密度为 ne / Zm，温度及流速沿用原主离子。

所有方案均保留电子。自动主离子取最低电荷的首个热离子，自动等效杂质
取电荷最高的原离子；也可以用下拉框明确指定。其他来源在生成 input.gacode
后自动识别；可切到该 input.gacode 再手动选择粒子。

准中性约束
~~~~~~~~~~

所有方案都强制满足密度和密度梯度准中性，没有关闭此处理的选项。
固定 ne 及其梯度，由主离子 m 补齐，其他离子记为 j：

.. math::

   n_m = (n_e - \sum_{j\ne m} Z_j n_j) / Z_m

.. math::

   g_m = (n_e g_e - \sum_{j\ne m} Z_j n_j g_j) / (Z_m n_m)

这里 g = -d ln(n)/dr，因而同时满足 sum(Z_i n_i)=ne 和
sum(Z_i n_i g_i)=ne ge。局部输入使用各程序一致的归一化梯度：
CGYRO 的 DLNNDR，TGLF 的 RLNS。主离子密度为零但剩余梯度不为零时停止。

等效杂质电荷为 Zq 时，以初次准中性校正后的 Zeff 为目标：

.. math::

   n_q = n_e (Z_{eff} - Z_m) / [Z_q (Z_q - Z_m)]

需要 Zq > Zm，且全部密度非负；所选杂质电荷不适合时提示重新选择。
仅容许浮点抵消产生的机器精度负数归零，不裁剪实际负密度。

完整剖面由 OMFIT 的 consistent_derived 更新派生量，再校正梯度；
远端生成每个半径输入后，重新校正主离子的密度、梯度及有效电荷。
TGYRO 使用主离子 DEN_METHOD1=-1，电子和其他离子不演化密度；
CALC_FLAG / THERM_FLAG 按当前粒子组成同步。
参数定义参见 https://gafusion.github.io/doc/tgyro/tgyro_list.html 。

生成结果与传递
~~~~~~~~~~~~~~

原始 INPUTS/input.gacode 保留以便切换方案；处理后的剖面保存在
OUTPUTS/Profiles_gen/input.gacode 和 Transfer_file/input.gacode。
OUTPUTS/Particle_processing 记录前后粒子组成、合并与独立热化的处理记录、密度及梯度残差、
Zeff 变化、压力最大相对变化及每个局部输入的校正残差。
热化与粒子简化一般改变压力、碰撞性或热输运模型；几何和径向网格不做更换。

“生成结果与传递”选择本次半径输入送入 CGYRO / TGLF；TGLF 覆盖由用户选择。
切换粒子方案后必须重新生成，旧生成结果不能作为新方案传递。
流程异常时恢复旧输出及本次改变的输入，成功时将上一轮输出归档。

“局部输入互转”是转换已有局部输入的独立页；上述粒子预设用于剖面生成。
“高级设置”编辑 Transfer_tool 的种子输入，缺少时自动使用内置种子。
统一计算环境仍在工程总控“环境配置与记录”中配置。
