Short Description
-----------------
准备 CGYRO 扫描输入、运行计算、收集和对比结果

Keywords
--------
CGYRO, linear, nonlinear, scans, gyrokinetics

Long Description
----------------
本模块准备、提交、收集和浏览 CGYRO 线性扫描。求解器与集群环境必须在
实际运行的 Linux/OMFIT 环境中配置。

Workflow
--------

1. 在“输入与扫描”选择 Transfer_tool 半径输入、导入文件或当前 CGYRO 输入。
   导入框显示实际选择的路径。半径可全选、清空或逐个选择。
2. 主离子方案选择“保持原始粒子”“H/D/T 对比”或“自选方案”。
   原始方案不改粒子组成；H/D/T 只修改 Z=1 主离子的质量。
3. 填写结果名称、ky 取值和扫描内容。可只扫 ky，也可增加 1–3 个物理参数。
   参数下拉菜单读取当前输入中的实际字段；取值使用列表。输入案例、离子方案、
   参数值与 ky 自动组合，页面显示计算点总数。
4. 在“计算参数”直接设置步长、运行时长、输出间隔、空间/速度网格、场和碰撞。
   直接修改数值并回车，自动应用到本轮所选半径与离子组合；不需要勾选。
   未修改的项目沿用各输入；每项“恢复”、本页恢复或全部恢复可撤销统一数值。
   可切换分组或搜索更多输入参数，扫描轴的取值优先于固定设置。
   时间与收敛参数也按分组和搜索筛选，不固定显示。积分方法使用下拉框直接选择。
   内置常用清单即使文件没有这些字段也显示；未载入文件时也可先配置。
   文件已有值优先，缺失时显示参考值，只有修改后才写入运行副本。
   更多常用参数包括耗散、碰撞守恒、输出选项以及 beta、平衡和剪切。
5. 回到“输入与扫描”点击“运行所选扫描”，自动准备输入、按统一环境提交、等待并收集。
   每次运行创建 ``runs/<运行标识>``，其中计算点固定命名为 ``p000001`` 等。
6. 收集后，``RUN_DB/结果名/案例`` 同时保存运行信息、``__TASKS__`` 任务坐标
   和实际 CGYRO 输出；``OUTPUTScan`` 保持原绘图入口兼容。
7. 在“结果与记录”选择记录并点击“查看当前数值表”。
   表格显示全部参数、ky、平均 omega/gamma 与相对波动；二维参数选择 ky，
   三维参数再选择第三轴切片。绘图为可选功能。

积分失败时，提示读取失败点的 ``out.cgyro.info`` 和作业日志，而非成功点的
日志；任务编号去重并显示 ky。求解器报告 ERROR 时，即使启动器返回 0 或产生了
部分时间输出，也不按成功结果归档。
``Integration error exceeded limit`` 表示积分误差超限。可在“计算参数”减小
``DELTA_T``，或设置 ``DELTA_T_METHOD=1`` 使用自适应 Cash-Karp；2 和 3 分别为
Bogacki-Shampine 与 Verner。0 为固定 RK4。修改后需重新计算，更新代码本身不会
补出失败点的数据；具体步长与收敛需在实际运行中确认。

原模块的 CGYRO GUI 与工程总控使用同一套界面。修改相关字段后即时更新计划和
按钮状态，不需要“刷新批量输入”。时间缩放与重启直接放在“计算参数”页，
完整源文件编辑作为可选入口。参数修改只作用于运行副本，原半径输入保留。
CGYRO 页面采用窄长布局：半径每行最多两项，每个扫描轴的参数和取值上下排列；
固定数值逐行直接编辑，输入框在右侧对齐。打开时按屏幕设置窄窗口，内容通过竖向
滚动浏览；之后保留手动调整的窗口尺寸。数值结果窗口也收窄，完整列可横向滚动。
固定设置、基础数值参数和各任务的实际时间设置保存到运行记录。
粒子组成由输入与主离子方案确定，密度/密度梯度不在固定参数页覆盖。
按 ky 缩放时间时，ky > 1 的步长和运行时长除以 ky；扫描步长或时长时需关闭缩放。
旧 time_scheme 设置自动迁移，历史记录仍可读取。
新工程默认保持原始粒子、只扫描 ky，不开启时间缩放；已有工程的设置继续保留。
本页面执行线性计算，NONLINEAR_FLAG 设为 0；其余源输入物理参数不再被自动清零。
“只扫 ky”不覆盖 beta 等物理参数，运行记录保存真实的固定输入坐标以兼容旧绘图视图。
提交和收集结束或出错后，当前源 input.cgyro 与当前案例设置恢复。
运行记录用空 OMFITtree 加 update(mapping) 创建；其第一个构造参数用于路径，不能传字典。

Restart and limitations
-----------------------

``restart_mode=1`` 只允许一个输入案例，并要求每个任务存在匹配的
``bin.cgyro.restart``。只有 ``MAX_TIME`` 和 ``PRINT_STEP`` 可以变化；其他输入
变化必须新建运行。重启使用新目录，原结果不覆盖。

Quasilinear/nonlinear comparisons require an explicit
PLOTS/nl/linear_range_by_case mapping and compatible species/field input metadata.
旧 GYRO 提交后端禁用。1.13.0 仅完成静态兼容检查，未运行真实求解器、集群作业
或完整 OMFIT GUI 会话。
