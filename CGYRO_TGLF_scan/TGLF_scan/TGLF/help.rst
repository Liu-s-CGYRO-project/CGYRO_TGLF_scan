Short Description
-----------------
Runs the TGLF code

Keywords
--------
Reduced gyrokinetic turbulence, transport model

Long Description
----------------
The TGLF code is a transport model that predicts particle, energy, and momentum flows based on local parameters (collisionalities, gradients, etc.).

Typical workflows
-----------------
This module is useful for
* running TGLF based on an existing TGLF input file
* scanning 1 or 2 parameters simultaneously to probe turbulent mode characteristics
* performing uncertainty quantification

Supported devices
-----------------
* Device independent
