Short Description
-----------------
Run the TRXPL TRANSP utility

Keywords
--------
TRANSP, statefile, transport

Long Description
----------------
This module allows extraction of a TRANSP statefile and gEQDSK from existing TRANSP simulations that are stored in MDS+ or NetCDF

Typical workflows
-----------------
This module is used to:

* extract NetCDF statefile and gEQDSK
* from TRANSP runs stored in MDS+ as well as NetCDF
* for individual or multiple time-slices

Supported devices
-----------------
* device independent
