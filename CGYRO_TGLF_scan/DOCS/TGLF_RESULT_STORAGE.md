# TGLF 原生结果保存

TGLF 使用原生扫描结构；CGYRO 的结果仍保存在 `CGYRO_scan/RUN_DB`。

| TGLF 方式 | 通量 | 完整结果 / 谱 |
| --- | --- | --- |
| 一维 | `scanResults` | `scanResults_spectra` |
| 二维 | `scanResults2D` | `scanResults2D_spectra` |
| 三维 | `scanResults3D` | `scanResults3D_spectra` |
| 不确定度 | `UQResults` | `UQResults_spectra` |
| 径向原值计算 | `Experimental_fluxes` | `Experimental_spectra` |
| 单文件原值计算 | — | `TGLF/FILES` |

由完整剖面生成的径向输入和 **Transfer_tool 生成的输入**，扫描都直接保存在 `TGLF_scan` 下，先按已有半径索引。例如一维通量在 `TGLF_scan['scanResults'][0.3]['SAT_RULE'][1]`，完整结果在 `TGLF_scan['scanResults_spectra'][0.3]['SAT_RULE'][1]`。运行前和“结果与记录”会显示具体保存路径。

当前单文件及局部互转输入使用原生单文件模块 `TGLF_scan/TGLF` 下的对应分支，不额外套半径。二维沿用原生的 `参数2+参数1 / 值2 / 值1`；三维按同样规则扩展为 `参数3+参数2+参数1 / 值3 / 值2 / 值1`，不写入二维分支。

新扫描不再创建 `sourceResults`。Transfer_tool 同批选择的输入若半径重复，会在提交前报告，请按输入方案分次扫描；不会让相同原生坐标静默覆盖同批的另一个点。半径只使用生成时保存的元数据，不把任务编号猜成半径。原生的 `TGLF_scan/TGYRO/RUN_DB` 是 TGYRO 输入生成及计算记录，不属于 TGLF 扫描结果库。

1.24.33–1.24.34 的 Transfer 结果可能在 `TGLF_scan['sourceResults']['transfer:编号']`。在“结果与记录”选择那条记录，点击 **“将这条记录归位到原生扫描”**，可把保留点移到上述原生位置，无需重算。只处理所选记录、同步既有结果引用；不在切页时自动搬迁。目标已有结果或来源半径不明确时保留原位置并报告，不猜测、不覆盖冲突。已经归位的点不会重复处理。

工作台的 `_workbench_runs` 保存本次状态、扫描坐标、通量摘要及结果路径；成功点的完整输入和输出仅由原生分支持有。`_workbench_index` 记录该路径当前属于哪个提交，防止旧运行记录显示成后一次计算。重置、原生重算和替换输入会失效相应引用。直接选择原生结果不依赖工作台运行记录。

新点先检查通量是否完整、有限，再更新对应通量和谱分支。下载失败的点保留诊断及原有可用结果；已成功的其他点照常保存。未选择的参数坐标和其他维度保留。

“结果与记录”可查看表格、可复制的点详情及单点谱；选择点时原位更新保存路径，不读取文件。对比绘图提供原生一维、二维和三维来源；三维使用标明第三轴取值的二维分片，不丢弃第三轴。切换页面和结果筛选不解析结果数组，绘图只读取选择的点。原生径向绘图直接接收所选半径的映射，不再复制、覆盖子模块的单文件扫描和输入。

更新时保留工程数据与设置。模板管理器不再把 TGLF 原生结果迁入 `RUN_DB`。旧版本已经写入 `TGLF_scan/RUN_DB` 的结果继续通过兼容入口读取，保留原文件和选择，不在打开页面时全库搬迁或复制；新提交按上表保存。更新后关闭并重开工作台和绘图窗口即可。
