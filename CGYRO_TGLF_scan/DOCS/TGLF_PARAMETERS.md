# TGLF 参数与扫描

在“TGLF 计算与扫描 → 计算参数”按模型、网格、碰撞与电磁、粒子与梯度、流与剪切、几何等分类查找参数。搜索直接输入名称或中文说明，无需引号，停止输入约 0.18 秒后过滤，回车可立即过滤。有搜索文字时查找全部参数，不受当前分组限制；清空后回到所选分组。每页最多显示 24 项，可用上一页/下一页查看；目录项数与匹配项数在搜索框下方显示。各字段和扫描参数下拉框旁的 `?` 显示含义、单位/归一化、取值和生效条件、参考来源。说明随代码提供，打开时不联网、不读取计算结果。

扫描参数目录逐项核对 GACODE 输入解析器的 177 个定义，不局限于当前 `input.tglf` 显式写出的字段。粒子字段按当前 `NS` 展开，省略 `NS` 时按解析器默认值 2 展开；当前输入中的新版扩展数值参数也会保留。`NS` 由物种组成管理，`USE_TRANSPORT_MODEL` 由工作台运行方式管理，参数页显示这两个值但不将其作为扫描轴；字符串 `UNITS` 有单独的选择框。新工程默认显示全部参数，旧工程保留已有分组与搜索设置。

显示值先取当前输入；输入未写出的字段显示官方解析器默认参考值。打开参数页、查看帮助或切换选项不会将整张默认表写入输入。只有手动修改的字段或所选扫描轴才写入任务副本；已有场景预设继续保持原来的成组设置。

## 参数预设与数值编辑

“计算参数”页顶部的“参数预设”下拉框与输入准备页共用同一套方案：Quench/SAT0、常规 SAT0/SAT1/SAT2、JET、ST、ITER。选择后应用对应模型参数，再按需要修改。内置方案只修改其定义的模型字段，其他手动设置保留。

单个数值参数均用输入框，包括 `SAT_RULE`、`KYGRID_MODEL` 等整数模型编号；修改后回车提交。逻辑开关、参数名称、归一化和预设方案仍使用选择控件。问号帮助保留各编号含义。普通数值提交不重建整页，也不触发 OMFIT 主数据树重绘；运行预览在下次查看时更新。选择预设只更新当前参数区域，搜索与翻页只替换列表。

`WIDTH_MIN` 允许非零负值，原符号写入计算输入。GACODE `tglf_max` 用其绝对值作为搜索下限；SAT2/3 中正值在初步宽度搜索时临时关闭电磁扰动，负值保留输入的 `USE_BPER/USE_BPAR`。`FIND_WIDTH=False` 时不使用 `WIDTH_MIN`，可以保留零值；开启搜索时，运行前会拒绝零值，因为源码计算 `log10(abs(WIDTH_MIN))`。校验使用扫描和固定参数合并后的实际输入，不在输入框中强制大于零。`NBASIS_MIN=0` 也保留原生含义：搜索阶段不切换到更少的基函数数。

点击“另存为我的预设”并输入名称，可保存当前明确修改的固定参数和归一化覆盖值。保存范围包括已应用的预设和之后的手动修改，不受“显示”分类或搜索条件限制；不包含沿用输入的字段、当前扫描轴、扫描取值列表、输入文件或结果。保存工程后，重开仍可从“我的预设 · 名称”选用。同名保存会确认替换。

应用自己的预设会替换当前的固定值覆盖集合，未保存的字段恢复沿用各输入；先校验整个预设，当前物种数不支持其中某个字段时不会部分应用。删除自己的预设只删除这一小份设置，当前参数和结果不受影响。预设仅保存在当前工程中，不是跨工程的全局配置。

## 扫描参数的控制范围

已选为一维、二维或 UQ 扫描轴的参数，在“计算参数”和输入准备的简要参数区显示“由扫描设置控制”，不再提供第二个固定值编辑入口。更换扫描轴或切回原始参数模式后恢复固定值编辑；原有手动值保留为非扫描时的设置。

执行扫描及生成输入时也排除扫描轴的固定值覆盖。因此，旧工程里残留的手动值不会改变倍数扫描的原值基准，也不会因无效旧值阻止合法的扫描列表。应用预设同样不能覆盖扫描列表。所有判断只使用当前设置和输入参数，不查找或解析结果。

- 一维/二维扫描支持连续数值、整数及逻辑值；逻辑参数使用 `[False, True]` 等列表。
- UQ 使用连续数值参数。原值为零时不能做倍数扫描，改用实际值范围或列表。
- 多半径的倍数扫描以各自输入为基准，不以该参数的固定值覆盖为基准；其他输入值保留。
- `SAT_RULE` 的已核对编号为 0、1、2、3；`KYGRID_MODEL` 的已核对编号为 0–5，在输入框填写。参数出现在目录中不保证旧服务器版本支持，具体以安装的 GACODE 为准。
- 扫描 `KY` 时留意网格模型：模型 0 以 `KY` 为最大波数；标准谱的 `NKY` 常表示高 ky 段点数，不一定是整个谱的总点数。

中文说明根据 [GACODE 参数字母列表](https://gacode.io/tglf/tglf_list.html)、[参数表](https://gacode.io/tglf/tglf_table.html) 和 [官方输入定义](https://github.com/gafusion/gacode/blob/master/tglf/bin/tglf_defaults.py) 核对，日期为 2026-10-27。默认值以输入定义为参考；官网两张表之间的差异、弃用项和未完整说明的专家项均作标注，不猜测单位。使用中的输入值优先于参考值。

旧工程更新代码后，关闭原工作台窗口再打开即可使用新目录及帮助；原有扫描选择、输入和结果保留，无需整理或重新收集结果。
