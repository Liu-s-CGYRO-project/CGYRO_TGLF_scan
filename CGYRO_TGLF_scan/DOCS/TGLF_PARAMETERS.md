# TGLF 参数与扫描

在“TGLF 计算与扫描 → 计算参数”按模型、网格、碰撞与电磁、粒子与梯度、流与剪切、几何等分类查找参数，也可切到“全部参数”后按名称或中文说明搜索。各字段和扫描参数下拉框旁的 `?` 显示含义、单位/归一化、取值和生效条件、参考来源。说明随代码提供，打开时不联网、不读取计算结果。

扫描参数目录包含 GACODE 输入解析器支持的标量参数，不再局限于当前 `input.tglf` 显式写出的字段。粒子字段按当前 `NS` 展开；当前输入中的新版扩展数值参数也会保留。`NS` 由物种组成管理，`USE_TRANSPORT_MODEL` 由工作台运行方式管理，不作为参数轴；字符串 `UNITS` 有单独的选择框。

显示值先取当前输入；输入未写出的字段显示官方解析器默认参考值。打开参数页、查看帮助或切换选项不会将整张默认表写入输入。只有手动修改的字段或所选扫描轴才写入任务副本；已有场景预设继续保持原来的成组设置。

- 一维/二维扫描支持连续数值、整数及逻辑值；逻辑参数使用 `[False, True]` 等列表。
- UQ 使用连续数值参数。原值为零时不能做倍数扫描，改用实际值范围或列表。
- 多半径的倍数扫描以各自输入为基准。扫描轴的值覆盖该参数的手动设置，其他输入值保留。
- `SAT_RULE` 列出 0、1、2、3；`KYGRID_MODEL` 列出源码支持的 0–5。参数出现在目录中不保证旧服务器版本支持，具体以安装的 GACODE 为准。
- 扫描 `KY` 时留意网格模型：模型 0 以 `KY` 为最大波数；标准谱的 `NKY` 常表示高 ky 段点数，不一定是整个谱的总点数。

中文说明根据 [GACODE 参数字母列表](https://gacode.io/tglf/tglf_list.html)、[参数表](https://gacode.io/tglf/tglf_table.html) 和 [官方输入定义](https://github.com/gafusion/gacode/blob/master/tglf/bin/tglf_defaults.py) 核对，日期为 2026-10-27。默认值以输入定义为参考；官网两张表之间的差异、弃用项和未完整说明的专家项均作标注，不猜测单位。使用中的输入值优先于参考值。

旧工程更新代码后，关闭原工作台窗口再打开即可使用新目录及帮助；原有扫描选择、输入和结果保留，无需整理或重新收集结果。
