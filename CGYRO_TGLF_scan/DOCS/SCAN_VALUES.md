# CGYRO 扫描取值

GUI 位于“CGYRO 扫描 → 输入与扫描 → 扫描设置”。列表输入沿用 OMFIT 原生数值表达式：填入 `np.linspace(0.1, 1.0, 10)` 并回车后，保存并显示实际数值。也可使用 `np.arange`、`np.logspace` 或实际列表。

ky 可选列表、线性范围、对数范围。参数轴可选列表、实际值范围、原值倍数、沿用输入。范围以起点、终点、点数定义，包含端点；点数为 1 时只取起点。原值倍数按各半径和主离子方案的输入分别计算。整数参数要求每个结果为整数，不自动取整。

切换参数时，列表默认取新参数在参考输入中的值，不沿用上一参数的小数。切换取值方式会保留手填列表；整数参数的实际范围按整数间隔初始化。例如 `[16, 24, 32, 48]` 对应的默认等步长范围是 16–48、5 点，避免按 4 点插值得到小数。切回列表仍保留原来的四个值；已设置且合法的自定义范围不重置。

## constant 固定参数

在扫描设置中选择固定参数、输入本次扫描的固定值并回车。例如扫描 N_THETA，同时设置 BETAE_UNIT=0.0001。该值独立于“计算参数”中的普通覆盖开关保存；切换标签、修改其他网格参数或更换参考输入不会把它重置成源文件值。准备扫描时将固定值写入运行副本，原输入文件不改动，归档案例按该固定条件分组。

计算参数页只显示 constant 的当前值，修改仍在扫描设置中进行。“本页沿用输入值”保留 constant；“全部沿用输入值”会明确取消 constant 及其他固定覆盖。旧工程沿用已保存的设置，无需重新建立索引；若该值此前已被旧版本覆盖，更新后需重新输入所需值并保存工程。

## 单变量收敛扫描

在同一个“扫描内容”下拉框选择 **单变量收敛扫描**。下方显示公共基准和检查方向，不另开一个工作页面。切回普通 ky / 多参数扫描会保留两种模式各自的设置。

先填写 N_ENERGY、N_XI、N_RADIAL、N_THETA、E_MAX 的基准值，再勾选检查方向并输入实际取值列表。每组自动包含该参数的基准值；其余参数保持公共基准和“计算参数”中的设置。需要更改该组对照条件时，填写“额外固定项”字典，例如能量上限组固定 `{'N_ENERGY': 64}`。时间步精度方向可单独勾选，默认关闭。“从参考输入载入基准与取值”是显式重置操作，会重新生成默认方向和取值。

各方向默认勾选“随基准更新”。上方基准回车生效后，仅对应方向的取值输入框原位更新。网格方向在基准上下取值，例如 NE16 → `[12, 16, 20]`、NE32 → `[24, 32, 40]`、NXI48 → `[32, 48, 64]`、NR24 → `[18, 24, 36]`、N_THETA32 → `[24, 32, 48]`。NE 的步长约为基准的 25%，取整且至少为 1；基准为 1 时不能生成更小的正整数，取 `[1, 2]`。NXI / NR / N_THETA 的外围候选按偶数取整。能量上限和时间精度沿用原先的方向：E_MAX8 → `[8, 10, 12]`，ERROR_TOL 取基准与更严格的十分之一。这些是初始对照范围，不代表已经收敛。额外固定项与其他方向保持各自设置。

方向标题中的 N_RADIAL 简写为“区间”，完整的 ballooning 区间名称和参数解释可通过旁边的 `?` 查看，避免长英文标题挤到下一行；其余布局规则不变。

手动修改某组“取值”并回车会关闭该方向的自动联动，之后改变基准仍保留手填列表；再次勾选“随基准更新”会立即按当前基准重新生成。该选择和手填列表随工程保存。开窗或切换标签不重新生成已有列表；旧配置首次出现该选项时默认勾选，只有显式修改基准或重新勾选才生成。联动只改对应轻量参数与现有控件，不重建标签页、不读取结果；修改后仍需重新预览计划。

例如基准 NE32 / NXI48 / NR32 / N_THETA32 / E_MAX8，手动指定 NE32/48/64、NXI32/48/64、NR24/32/48、N_THETA24/32/48，另以 NE64 扫 E_MAX8/10/12。相同完整配置只计算一次，公共基准单列为 Base case；E_MAX 的 NE64 / E_MAX8 基准共享 N_ENERGY=64 的结果。因此这份指定计划仍是 11 个唯一配置；7 个 ky 对应 77 点，归档分为公共基准及五个方向，统一提交为一个 Slurm 数组主作业。勾选 ERROR_TOL 的额外对照后可增加到 12 配置、84 点，不做全组合。若 NE 采用新的默认 `[24, 32, 40]`，则 NE64 / E_MAX8 不在能量方向中，需单独保留该组基准，五个方向合计 12 配置、84 点；实际数量以预览为准。

“预览收敛扫描计划”列出分组数、候选点、可复用点、数组主作业数和新计算子任务数；每个仍有新点的半径 / 离子方案计一个主作业，全部复用时为 0，不提交作业。默认只在当前结果名称、相同半径/离子的轻量索引中，按已收集的输入元数据、有效文件引用和状态摘要复用结果，可跨方向匹配共享基准。输入参数、输出设置和精度必须匹配；已收敛结果可提前结束，正常到时结果必须达到所需绝对终点。旧摘要不足、部分失败、引用失效或同坐标存在不同结果所有者的点安排新计算，不为补齐索引打开所有结果文件。取消勾选复用可明确重算。

点击原有“运行所选扫描”，每个半径 / 离子方案下的公共基准及检查方向合并到同一个数组主作业，不同半径或离子方案分别提交；已复用的点从提交列表排除。例如选择两个半径和 H / T 两种离子，会提交 4 个数组主作业。各子任务使用当前统一的节点、MPI、线程与时间配置，Slurm 并发点数限制分别作用于每个案例数组。输出选项沿用当前计算配置。本功能不自动判断网格是否收敛，也不自动延长 MAX_TIME。

更改基准后，准备扫描时会把可复用结果的引用登记到本次 `Base case` 与方向索引；即使所有点都已存在、不需提交作业，绘图也使用本次基准。此步骤只更新所选案例涉及的索引，不复制结果文件，提交索引失败时恢复原记录；预览不会修改归档。

每个案例数组保存本案例全部提交点的冻结输入 ZIP、点表和恢复清单，每点保留自己的半径、离子和方向身份，可按对应主作业号恢复。不同来源结果名或 constant 坐标也分别提交，不混入同一个数组。新收敛扫描在结果名称后加一次 `_convergence`，例如：

```text
RUN_DB
└── Jet_convergence
    └── nr=1_rho=0.33_BETAE_UNIT=0.0001
        └── T
            ├── Base case
            ├── N_ENERGY
            ├── N_XI
            ├── N_RADIAL
            ├── N_THETA
            └── E_MAX
```

未设置 constant 时省略固定参数后缀，其他主离子方案放在对应 H / D / T 下。归档继续按完整参数坐标合并：未选点和其他方向保留，验证通过的新计算替换相同坐标。若部分点失败，已有可读结果仍可独立归档；本次提交完成与参数分支完整性分别记录。共享基准引用同一个物理结果，不复制文件到每个方向。

在“CGYRO 对比 → 案例选择”选择记录和半径 / 离子，勾选独立的 **convergence_test** 选择框。下方只显示收敛方向和取值；取消勾选后只显示常规扫描参数，两类选择分别记忆，不再使用“绘图案例”下拉框。常规列表按每点的收敛索引排除收敛方向及 Base case，即使旧归档把两类点放在同一参数分支也分别筛选，不移动或删除已有结果。

绘图窗口仍称为“收敛测试”，顶部按 **N_RADIAL、N_THETA、N_ENERGY、N_XI、E_MAX…** 分标签页，每个方向单独一张图。频率与增长率分别绘制，开启波动指标时采用 2×2 布局；各方向不再挤在一张宽图中。基准自动匹配并用黑色虚线标出，标题注明基准值与统计窗口。不同半径、离子、运行记录或固定物理条件的同名方向保持独立标签页。切换 convergence_test 仅刷新当前参数选择区，不刷新外层窗口或解析结果文件。

列表只查询所选案例的轻量索引；点击绘图后才读取勾选方向及匹配基准的结果。跨方向共享须匹配已收集的 `input.cgyro.gen` 全参数摘要、半径 / 离子和带符号 ky。缺失或不一致的基准明确报告并保留缺口，不拿另一物理条件的结果代替。真实多参数扫描仍使用“常规扫描”的完整坐标筛选。

旧工程不自动搬动结果。已有 `convergence_group` 和生成输入摘要的旧归档可直接使用新绘图，并从原分支引用基准；无法证明扫描方向或参数身份的旧记录仍按普通扫描显示。新命名空间的复用只查询该命名空间，不能把旧目录里的结果误算成已归档的新结果。更新后关闭重开总控即可读取兼容索引，无需恢复历史作业链。

## 远程批量排队

“运行所选扫描”对 Slurm / PBS 的多个半径 / 离子案例先全部提交，再等待并分别收集。例如选择一个半径的 H / D / T，会先得到三个作业号，不等待 H 结束才提交 D 和 T。队列决定实际开跑顺序和并行程度；Slurm 并发点数是每个案例数组的上限，多案例总并发可能更高。单变量收敛扫描把同一案例的基准与全部方向合并在该案例数组中。

RUN_BATCH 关联本批计划与 token，RUN_DB/__RUNS__ 保存各例的独立目录、点表、作业号和未归档引用，RUN_HISTORY 只存任务身份与状态。“同步作业状态”同步整批 Slurm 作业；“重新收集未归档结果”只收集已有输出，不补算，遇到活动案例会报告并继续其他案例。Slurm 等待窗口的 Kill local 请求取消本批未结束作业，并停止本地等待；失败可重试。部分失败保留其他任务与成功结果；各点在核验后独立归档。

本地计算继续同步运行，重启只允许一个案例。该排队方式不会更改已提交的旧任务。

### 不同参数追加，同一参数重扫覆盖

同一结果名（如 Jet）、半径和 H / D / T 案例下，先扫描 N_THETA、再扫描 N_ENERGY，会按参数分支显示。绘图仍先选半径、再选离子，然后选择参数分支。归档按完整物理参数坐标合并：新计算核验后替换相同坐标的结果，未选取值、ky 和其他分支保留；续算优先保留已收敛或模拟时间更大的有效结果。

参数分支按有序参数轴及联动参数组织，不包含取值、ky 网格和运行 UUID。二维 / 三维组合单独显示（例如 N_THETA__N_ENERGY）；仅 ky 扫描使用 KY_ONLY。点的身份还包含半径、离子、带符号 ky 及完整输入参数。背景固定值不同的点可以保留；若需在树上区分固定条件，可使用 constant 分组或不同结果名。

每个扫描的任务表和运行记录位于 RUN_DB/结果名/案例/__SCANS__/扫描键/tasks 和 info。结果浏览器按参数组列出记录，ky 续算仅修改所选记录的点；另一参数组的 p000001 不与它混用。旧单记录案例在下次归档时迁移，仍存在的旧 UUID 案例按扫描组合合并。

更新不会凭空恢复旧版本已覆盖的数据。RUN_HISTORY 中归档后的记录通常只有目录和运行信息，重复结果副本及点表已移除；恢复需要仍存在的原结果目录及对应 manifest.json（含点表），或覆盖前保存的工程。不要把“重新收集未归档结果”当作所有已归档历史扫描的恢复入口，也不要用当前 GUI 参数重建旧运行的坐标。

### 偶发失败重试

运行页“失败点重试次数”可填 0–3，默认 2，0 关闭自动补算，仅对用户发起的运行 / 续算流程生效。手动收集即使该值为 2 也不提交计算。服务器确认作业已结束后，仅对可重试的失败点用原始输入补跑，使用新目录；成功点仍从原目录读取，全部点完整后才归档。手动取消、超时、内存不足、明确输入 / 积分错误不反复提交；参数和资源不自动修改。读取或网络错误最多重读两次，先核实提交日志取得作业号，不能确认时保留状态并阻止盲目重复提交。

Slurm 补跑保持原数组索引，并用 `--array=失败索引列表%并发上限` 选择失败点，参见 [sbatch](https://slurm.schedmd.com/sbatch.html)；PBS 生成只含失败点的列表。各轮作业号、目录和状态进入 attempts，point_workdirs 标记每个点的实际结果来源，原目录和日志均保留。

程序接口与扩展示例见 GitHub 仓库根目录 [SCAN_VALUES_REFERENCE.md](https://github.com/Liu-s-CGYRO-project/CGYRO_TGLF_scan/blob/main/SCAN_VALUES_REFERENCE.md)。预检查与实际提交共用 cgyro_scan_values，返回实际轴取值，不改原始输入。

## 粒子处理与 H / D / T

H / D / T 扫描合并识别出的热主离子，只改变合并主离子质量，保留辅助组。Transfer_tool 在原始完整剖面副本上先校正准中性，再执行所选粒子方案；原载入文件和已归档结果保留。

“仅保留主离子和 Zeff”使用校正后的完整源粒子组成计算的 Zeff，主离子密度和补齐为 1；CGYRO 指定 Z_EFF_METHOD=1 与碰撞模型 1 / 5。四组方案的热杂质温度跟随热主离子，快粒子独立保压，并报告压力及梯度变化。模型选择、守恒约束和限制见 [粒子处理完整说明](https://github.com/Liu-s-CGYRO-project/CGYRO_TGLF_scan/blob/main/TRANSFER_PARTICLES_REFERENCE.md)。

GAMMA_E 在“平衡与剪切”，Z_EFF / Z_EFF_METHOD 在“场与碰撞”；输入格式与生效条件见参数旁“?”。旧生成记录的规则不匹配时需重新生成，不能把旧输入当成新方案。

## 参数帮助接口

### 完整计算参数目录

计算参数目录已按原生 `cgyro/bin/cgyro_parse.py` 核对全部 247 个展开参数（GACODE Git blob `f2d22f2a30e95d36ae06c85c66d95d05985767f8`，2026-10-29）。其中 199 项由计算参数页编辑，即使当前 input.cgyro 省略这些项也能搜索到；53 项保留在常用设置。其余 48 项由已有流程管理：KY 使用 ky 取值，NONLINEAR_FLAG / N_TOROIDAL 由线性单模提交器管理，N_SPECIES 及 Z、MASS、DENS、DLNNDR 的 1–11 号字段由源输入与离子配置管理，不提供冲突的固定覆盖入口。粒子温度、温度梯度、曲率和实验剖面倍率的 1–11 号字段已纳入目录。

`HIPREC_FLAG` 同时出现在常用设置和输出选项中；0 为原生单精度二进制输出，1 为双精度输出。需要双精度场与粒子矩数据时，分别设置 HIPREC_FLAG=1、FIELD_PRINT_FLAG=1、MOMENT_PRINT_FLAG=1；H_PRINT_FLAG 是独立的分布函数输出开关，不会自动打开。省略项显示原生参考值，只有修改并回车后才覆盖运行副本；旧输入、已保存的显式覆盖和未修改的默认值均不被自动改写。

本次还核对了太原当前解析器：上述 247 项的名称与默认值一致，另有 7 项 TRIAD / FULL_T 站点扩展。扩展项继续从支持它们的当前输入中发现，不把站点专用选项无条件写入其他 GACODE 版本。原生目录与 [解析器源码](https://github.com/gafusion/gacode/blob/master/cgyro/bin/cgyro_parse.py) 对照，保留离线目录，不在开窗或搜索时联网。

搜索使用已捕获的名称与中文标签，停止输入约 0.18 秒后筛选，回车立即筛选。清空后恢复所选分组并回到第一页，每页最多 24 行。只替换参数行及更新匹配/分页计数，保留搜索框、参考输入、外层标签、时间缩放和重启选项；刷新被保存操作延迟或构建期间收到新的筛选时，按最新状态补做同一面板。不会因此读取 RUN_DB 结果、计算文件哈希、复制输入 ZIP 或整理归档。

“计算参数”和扫描轴的“?”提供可输入值、物理含义、单位和生效条件。说明与扩展接口见完整参考；未核对的参数不按名称猜测含义。

说明为随包提供的中文数据，离线可用；“?”使用可滚动窗口，较长的说明不会被截断。输入框继续只接受参数值，物理解释不混入数值字段。Z_EFF_METHOD 采用普通数值输入框，填 1 或 2，回车生效。

来源为 [官网字母索引](https://gacode.io/cgyro/cgyro_list.html)、[归一化与分类表](https://gacode.io/cgyro.html)、[旋转定义](https://gacode.io/rotation.html)，并核对上述固定源码版本。官网部分默认值与新版源码不同，界面不据网页强行修改源输入或 GUI 参考值；输入值和参考值在帮助末尾单独显示。EQUILIBRIUM_MODEL 的官网旧项 3 与新版仅接受 1 / 2 的差异已标注；新版模型 2 为 Miller Extended Harmonic（MXH）。COLLISION_MODEL 的 6 / 7 也注明版本限制。

重要生效条件包括：线性计算不使用 GAMMA_E；独立指定 Zeff 需要 Z_EFF_METHOD=1 和碰撞模型 1 / 5；多数实验剖面倍率只对 PROFILE_MODEL=2 生效，局部输入应直接调整对应物理量。帮助说明输入约定，不替代服务器自身的版本检查与数值收敛检查。
