# CGYRO 扫描取值

GUI 位于“CGYRO 扫描 → 输入与扫描 → 扫描设置”。列表输入沿用 OMFIT 原生数值表达式：填入 `np.linspace(0.1, 1.0, 10)` 并回车后，保存并显示实际数值。也可使用 `np.arange`、`np.logspace` 或实际列表。

ky 可选列表、线性范围、对数范围。参数轴可选列表、实际值范围、原值倍数、沿用输入。范围以起点、终点、点数定义，包含端点；点数为 1 时只取起点。原值倍数按各半径和主离子方案的输入分别计算。整数参数要求每个结果为整数，不自动取整。

切换参数时，列表默认取新参数在参考输入中的值，不沿用上一参数的小数。切换取值方式会保留手填列表；整数参数的实际范围按整数间隔初始化。例如 `[16, 24, 32, 48]` 对应的默认等步长范围是 16–48、5 点，避免按 4 点插值得到小数。切回列表仍保留原来的四个值；已设置且合法的自定义范围不重置。

## 单变量收敛扫描

在同一个“扫描内容”下拉框选择 **单变量收敛扫描**。下方显示公共基准和检查方向，不另开一个工作页面。切回普通 ky / 多参数扫描会保留两种模式各自的设置。

先填写 N_ENERGY、N_XI、N_RADIAL、N_THETA、E_MAX 的基准值，再勾选检查方向并输入实际取值列表。每组自动包含该参数的基准值；其余参数保持公共基准和“计算参数”中的设置。需要更改该组对照条件时，填写“额外固定项”字典，例如能量上限组固定 `{'N_ENERGY': 64}`。时间步精度方向可单独勾选，默认关闭。“从参考输入载入基准与取值”是显式重置操作，会重新生成默认方向和取值。

例如基准 NE32 / NXI48 / NR32 / N_THETA32 / E_MAX8，分别扫描 NE32/48/64、NXI32/48/64、NR24/32/48、N_THETA24/32/48，另以 NE64 扫 E_MAX8/10/12。相同完整配置只计算一次，重复基准由最先请求它的方向持有，其他组在计划中注明共享来源。因此是 11 个唯一配置；7 个 ky 对应 77 点。勾选 ERROR_TOL 的额外对照后可增加到 12 配置、84 点，不做全组合。

“预览收敛扫描计划”列出候选点、新提交点、可复用点和作业数；不提交作业。默认只在当前结果名称、相同半径/离子及对应参数分支中，按已收集的输入元数据、有效文件引用和轻量状态摘要复用结果。输入参数、输出设置和精度必须匹配；已收敛结果可提前结束，正常到时结果必须达到所需绝对终点。旧摘要不足、部分失败或引用失效的点安排新计算，不为补齐索引打开所有结果文件。取消勾选复用可明确重算。

点击原有“运行所选扫描”，每个半径 / 离子 / 检查方向生成一份普通一维扫描作业；已复用的点从提交列表排除。资源、时间和输出选项沿用当前计算与运行配置。本功能不自动判断网格是否收敛，也不自动延长 MAX_TIME；完成后使用现有结果表和绘图比较各方向。

各作业保留独立的输入 ZIP、点表和恢复清单，可按实际主作业号恢复。结果仍保存到 RUN_DB，并通过完整参数坐标合并：未选点和其他检查方向保留，验证通过的新计算替换相同坐标。若部分点失败，已有可读结果仍可独立归档；本次提交完成与参数分支完整性分别记录。共享基准保存在首次计算它的参数分支，不复制到其他分支。

## 远程批量排队

“运行所选扫描”对 Slurm / PBS 的多个案例先全部提交，再等待并分别收集。例如选择一个半径的 H / D / T，会先得到三个作业号，不等待 H 结束才提交 D 和 T。队列决定实际开跑顺序和并行程度；Slurm 并发点数是每个案例数组的上限，多案例总并发可能更高。

RUN_BATCH 关联本批计划与 token，RUN_DB/__RUNS__ 保存各例的独立目录、点表、作业号和未归档引用，RUN_HISTORY 只存任务身份与状态。“同步作业状态”同步整批 Slurm 作业；“重新收集未归档结果”只收集已有输出，不补算，遇到活动案例会报告并继续其他案例。Slurm 等待窗口的 Kill local 请求取消本批未结束作业，并停止本地等待；失败可重试。部分失败保留其他任务与成功结果；各点在核验后独立归档。

本地计算继续同步运行，重启只允许一个案例。该排队方式不会更改已提交的旧任务。

### 不同参数追加，同一参数重扫覆盖

同一结果名（如 Jet）、半径和 H / D / T 案例下，先扫描 N_THETA、再扫描 N_ENERGY，会按参数分支显示。绘图仍先选半径、再选离子，然后选择参数分支。归档按完整物理参数坐标合并：新计算核验后替换相同坐标的结果，未选取值、ky 和其他分支保留；续算优先保留已收敛或模拟时间更大的有效结果。

参数分支按有序参数轴及联动参数组织，不包含取值、ky 网格和运行 UUID。二维 / 三维组合单独显示（例如 N_THETA__N_ENERGY）；仅 ky 扫描使用 KY_ONLY。点的身份还包含半径、离子、带符号 ky 及完整输入参数。背景固定值不同的点可以保留；若需在树上区分固定条件，可使用 constant 分组或不同结果名。

每个扫描的任务表和运行记录位于 RUN_DB/结果名/案例/__SCANS__/扫描键/tasks 和 info。结果浏览器按参数组列出记录，ky 续算仅修改所选记录的点；另一参数组的 p000001 不与它混用。旧单记录案例在下次归档时迁移，仍存在的旧 UUID 案例按扫描组合合并。

更新不会凭空恢复旧版本已覆盖的数据。RUN_HISTORY 中归档后的记录通常只有目录和运行信息，重复结果副本及点表已移除；恢复需要仍存在的原结果目录及对应 manifest.json（含点表），或覆盖前保存的工程。不要把“重新收集未归档结果”当作所有已归档历史扫描的恢复入口，也不要用当前 GUI 参数重建旧运行的坐标。

### 偶发失败重试

运行页“失败点重试次数”可填 0–3，默认 2，0 关闭自动补算，仅对用户发起的运行 / 续算流程生效。手动收集即使该值为 2 也不提交计算。服务器确认作业已结束后，仅对可重试的失败点用原始输入补跑，使用新目录；成功点仍从原目录读取，全部点完整后才归档。手动取消、超时、内存不足、明确输入 / 积分错误不反复提交；参数和资源不自动修改。读取或网络错误最多重读两次，先核实提交日志取得作业号，不能确认时保留状态并阻止盲目重复提交。

Slurm 补跑保持原数组索引，并用 `--array=失败索引列表%并发上限` 选择失败点，参见 [sbatch](https://slurm.schedmd.com/sbatch.html)；PBS 生成只含失败点的列表。各轮作业号、目录和状态进入 attempts，point_workdirs 标记每个点的实际结果来源，原目录和日志均保留。

程序接口与扩展示例见 GitHub 仓库根目录 [SCAN_VALUES_REFERENCE.md](https://github.com/Liu-s-CGYRO-project/CGYRO_TGLF_scan/blob/main/SCAN_VALUES_REFERENCE.md)。预检查与实际提交共用 cgyro_scan_values，返回实际轴取值，不改原始输入。

## 粒子处理与 H / D / T

H / D / T 扫描合并识别出的热主离子，只改变合并主离子质量，保留辅助组。Transfer_tool 在原始完整剖面副本上先校正准中性，再执行所选粒子方案；原载入文件和已归档结果保留。

“仅保留主离子和 Zeff”使用校正后的完整源粒子组成计算的 Zeff，主离子密度和补齐为 1；CGYRO 指定 Z_EFF_METHOD=1 与碰撞模型 1 / 5。四组方案的热杂质温度跟随热主离子，快粒子独立保压，并报告压力及梯度变化。模型选择、守恒约束和限制见 [粒子处理完整说明](https://github.com/Liu-s-CGYRO-project/CGYRO_TGLF_scan/blob/main/TRANSFER_PARTICLES_REFERENCE.md)。

GAMMA_E 在“平衡与剪切”，Z_EFF / Z_EFF_METHOD 在“场与碰撞”；输入格式与生效条件见参数旁“?”。旧生成记录的规则不匹配时需重新生成，不能把旧输入当成新方案。

## 参数帮助接口

“计算参数”和扫描轴的“?”提供可输入值、物理含义、单位和生效条件。说明与扩展接口见完整参考；未核对的参数不按名称猜测含义。

说明为随包提供的中文数据，离线可用；“?”使用可滚动窗口，较长的说明不会被截断。输入框继续只接受参数值，物理解释不混入数值字段。Z_EFF_METHOD 采用普通数值输入框，填 1 或 2，回车生效。

来源为 [官网字母索引](https://gacode.io/cgyro/cgyro_list.html)、[归一化与分类表](https://gacode.io/cgyro.html)、[旋转定义](https://gacode.io/rotation.html)，并核对上述固定源码版本。官网部分默认值与新版源码不同，界面不据网页强行修改源输入或 GUI 参考值；输入值和参考值在帮助末尾单独显示。EQUILIBRIUM_MODEL 的官网旧项 3 与新版仅接受 1 / 2 的差异已标注；新版模型 2 为 Miller Extended Harmonic（MXH）。COLLISION_MODEL 的 6 / 7 也注明版本限制。

重要生效条件包括：线性计算不使用 GAMMA_E；独立指定 Zeff 需要 Z_EFF_METHOD=1 和碰撞模型 1 / 5；多数实验剖面倍率只对 PROFILE_MODEL=2 生效，局部输入应直接调整对应物理量。帮助说明输入约定，不替代服务器自身的版本检查与数值收敛检查。
