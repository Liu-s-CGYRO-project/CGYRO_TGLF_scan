# 多参数扫描绘图

在“案例选择”先选运行记录、半径和离子，再勾选扫描组合。二维扫描分别显示两条参数轴的取值；三参数扫描分别显示三条轴。每一条取值列表都参与筛选，重置恢复该轴的原扫描取值。保留旧版第一条轴的选择，新增轴初次使用全部原取值；不会重新计算或改写 RUN_DB。

“变化参数”可选择任意一条独立扫描轴。谱图、时间曲线和本征函数为每个完整参数组合读取各自保存的 ky 数据，图例列出全部参数。指定 ky 的参数扫描、增长率比值以及三维图让所选参数变化，其他参数的每个固定组合分别成组。

例如扫描 N_ENERGY、N_XI、N_THETA，选择 N_ENERGY 为变化参数：每个固定的 (N_XI, N_THETA) 组合单独比较 N_ENERGY。三维图每组一页，两个水平坐标为 ky 和 N_ENERGY，两个子图分别显示频率和增长率；它不是把三条参数轴压成一个坐标，也不把不同固定组合平均。

联动参数仍跟随所属的独立轴，不变成新的笛卡尔维度；图例和导出保留其实际取值。普通一参数扫描和旧版一参数归档继续使用原路径。

部分结果只绘制实际保存的数据。指定 ky 的参数网格用 NaN 保留缺失的参数行，网格不完整时三维图使用散点，不插值或填零；谱图使用该组合实际保存的 ky。缺失或无效数据会说明并跳过，全部所选组合均不可用时才报无数据。

CGYRO 自对比、时间曲线、本征函数、谱导出、CGYRO / TGLF 对比和输出状态检查共用完整坐标视图。导出的说明和元数据记录原扫描键、变化参数及全部参数坐标，避免重名曲线；不修改原始结果。

更新后关闭旧工程总控和绘图选择窗口，重新打开以加载新 LIB 与回调。已有的完整及 partial 多参数归档可直接使用，不需要重算或重新收集。只有缺少原始扫描坐标或文件的旧数据仍需要先核对归档来源。

本版完成静态、OMFIT API / LIB 依赖和安装包校验；没有启动 GUI、绘图、科学函数或集群任务，服务器显示效果尚未实测。
